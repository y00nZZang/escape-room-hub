# Security policy

Please report suspected credential exposure, unsafe provider behavior, or a data-distribution policy
bypass privately through GitHub's security advisory feature. Do not include credentials, cookies,
tokens, booking-customer data, or raw third-party responses in a public issue.

The project must stop a provider on authentication requirements, CAPTCHA, `401`, `403`, or `429`.
Bypassing access controls, rotating identities or IP addresses, and replaying private sessions are
outside the project scope.
