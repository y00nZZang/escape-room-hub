# Third-party data and trademarks

This repository contains software scaffolding only. It does not grant permission to access, copy,
cache, transform, redistribute, or otherwise use any third-party website, API, database, content,
brand, or trademark.

- The source code is publicly visible but is not distributed under an open-source license.
- Provider code, configuration, or documentation does not establish authorization from a source
  operator.
- Real providers must remain disabled until their access basis, terms, robots policy, allowed
  fields, retention, request interval, and distribution scope have been reviewed.
- Images, descriptions, reviews, ratings, booking-customer data, cookies, tokens, raw HTML/JSON,
  and long-term availability histories are outside the intended dataset.
- Booking always remains on the operator's official page. This project is not a booking service and
  does not represent an affiliation with any venue or platform.

Rights holders can request correction or removal by opening a GitHub issue in this repository.
